The controls listed below are the server defaults for Ashburn Creek. If you have remapped keys inside RedM, your bindings may differ from what you see here. Use this page as a reference point, and adjust the actions in your RedM settings whenever a default conflicts with your preferred layout.

<Tip>
  To rebind any key, open **RedM → Settings → Key Bindings**, search for the action name, and assign a new key. Changes take effect immediately without a restart.
</Tip>

## Movement

Use the standard movement keys to navigate on foot. The ragdoll key can get your character out of tight spots or geometry snags.

| Key | Action |
|-----|--------|
| `W` | Move forward |
| `A` | Move left |
| `S` | Move back |
| `D` | Move right |
| `Z` | Ragdoll |

## Essential Controls

These binds cover horse handling, the map, your inventory, and the interaction menu you will use throughout every session.

| Key | Action |
|-----|--------|
| `H` | Whistle Horse |
| `U` | Open Hotbar |
| `E` | Get On / Off Horse |
| `M` | Open Map |
| `C` | Look Behind You |
| `X` | Raise Hands |
| `L` | Point |
| `I` | Open Inventory |
| `J` | Set Voice Range |
| `Caps Lock` or `Middle Mouse Wheel` | Open Interaction Menu |
| `F6` | Open Dance Menu |
| `Hold V` | Toggle Cinematic Mode |

## Roleplay & Stance Keys

Roleplay commands are entered in chat and give other players context for your character's actions, feelings, and surroundings. Stance commands let you hold a specific pose or animation to support a scene. For full descriptions and the complete stance list, see the [RP Commands](/gameplay/roleplay-commands) guide.

### Quick Command Reference

| Command | What it does |
|---------|--------------|
| `/me` | Describes your character's action or expression to nearby players |
| `/do` | Adds scene detail or describes something observable in the environment |
| `/try` | Shows your character attempting an uncertain action |
| `/hurt` | Communicates your character's visible wounds or pain |
| `/tag` | Adds a visible description of something about your character |
| `/kys` | Immediately downs your character — use only when physically stuck |
| `/guide` | Displays helpful in-game tips *(coming soon)* |

### Stance Command

Type `/s` followed by a stance name to hold a pose or looping animation. For example, `/s sitg` sits your character on the ground; `/s stand` clears the stance and returns to default. The full stance list is in the [RP Commands](/gameplay/roleplay-commands) guide.
